# A.R.I.A. v0.34

**Download the package for your system below, unpack it into the top folder of a USB drive (exFAT) and start her.** Step-by-step instructions are in `ARIA-User-Manual.pdf`, included in every package.

| File | For |
|---|---|
| `ARIA-USB-Windows.zip` | Windows 10 / 11 (64-bit) |
| `ARIA-USB-macOS.zip` | macOS 12+ — Apple Silicon and Intel |
| `ARIA-USB-Linux.zip` | 64-bit Linux (AppImage) |

## What's new
- **A real terminal** in the workspace: PowerShell (Windows), zsh (macOS), bash (Linux).
- **The workspace on any monitor**: the ⧉ button, or drag its bar past the edge of the window.
- **Support me** in Settings: buy the author a coffee by QR code (Apple Pay, Google Pay, wallet) or in the browser.
- **Blueprint**: a Clear button, alongside the full drawing toolbox.
- **Tidier settings**: every page folds into groups that show their current state.
- **Apps in the ARIA style**: ask “build a notes app in ARIA style”.
- **Built-in local models**, device detection (printers, drives, USB), wake-up greeting, native-language voices.
- The app is now called **A.R.I.A.** everywhere; settings from earlier versions are kept.

## Updating
Close A.R.I.A., unpack the new package into the top folder of the drive and allow the files to be replaced. `ARIA-data` (settings, keys, voices, models) is never touched.
